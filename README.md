# Tapper

특정 좌표를 지정한 간격으로 연타하는 macOS 메뉴바 앱.
iPhone 미러링 창을 통해 아이폰 화면을 대상으로 쓸 수 있습니다.

```
┌─────────────────────────────┐
│ 좌표   (412, 638)   [지정]  │
│ 간격   ──────●──── 100ms    │
│ 모드   ◉ 토글 ○ 시간 ○ 횟수  │
│      [ 시작  ⌥⌘S ]          │
│ ● 연타 중 · 38회 · 9.4 tap/s│
└─────────────────────────────┘
```

## 필요 환경

| 항목 | 요구사항 |
|---|---|
| 맥 | **Apple Silicon** (M1 이상) |
| macOS | 13 이상 — 아이폰 대상으로 쓰려면 **15 이상** |
| 아이폰 | iOS 18 이상, 맥과 같은 Apple ID |
| 개발 도구 | Xcode Command Line Tools |

Intel 맥에서는 iPhone 미러링이 동작하지 않습니다.

## 설치

```bash
git clone https://github.com/ae-hyon/tapper.git
cd tapper && ./install.sh
```

`install.sh`가 환경 점검 → 서명 인증서 생성 → 빌드 → `/Applications` 설치까지
처리합니다. 설치 전에 환경만 확인하려면:

```bash
./install.sh --check-only
```

### Xcode Command Line Tools가 없다면

설치 스크립트가 알려주지만, 미리 받아두면 빠릅니다:

```bash
xcode-select --install
```

창이 뜨고 수 GB를 내려받습니다. 완료 후 `install.sh`를 실행하세요.

## 첫 실행 — 권한 설정

**이 단계를 건너뛰면 앱이 아무 동작도 하지 않습니다.**

1. 권한 요청 창이 뜨면 승인합니다. 안 뜨면 메뉴바 아이콘 → **권한 요청**
2. 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용**에서 Tapper를 켭니다
3. **앱을 재시작합니다** — 메뉴바 아이콘 → 종료 후 다시 실행
4. 메뉴바 아이콘을 눌러 주황색 배너가 사라졌으면 완료

3번이 중요합니다. macOS는 프로세스 시작 시점의 권한 상태를 고정하므로,
실행 중에 권한을 줘도 그 프로세스는 계속 거부됩니다.

권한이 없으면 클릭이 **에러 없이 조용히 버려집니다.** 그래서 앱은 그 상태에서
시작을 거부하고 배너로 알립니다.

## 사용법

| 핫키 | 동작 |
|---|---|
| `⌥⌘C` | 커서가 놓인 지점을 대상 좌표로 저장 |
| `⌥⌘S` | 연타 시작 / 정지 |
| `⌥⌘.` | 긴급 정지 |

전역 핫키이므로 **대상 창에서 포커스를 뺄 필요가 없습니다.** 커서를 원하는
지점에 올려두고 `⌥⌘C`, 그다음 `⌥⌘S`로 시작하면 됩니다.

### 모드

- **토글** — 다시 누를 때까지 계속
- **시간** — 지정한 초가 지나면 자동 정지 (1초 단위, 키보드 입력 가능)
- **횟수** — 지정한 횟수를 채우면 자동 정지 (1회 단위, 키보드 입력 가능)

### 설정

| 항목 | 범위 | 기본값 |
|---|---|---|
| 간격 | 5–2000ms | 100ms |
| 누름 유지 | 1–100ms | 15ms |
| 시작 지연 | 0–10초 | 3초 |

간격을 내리면 누름 유지가 자동으로 따라 내려갑니다(간격의 1/3). 누름이 간격보다
길면 실효 속도가 무너지기 때문입니다.

### 아이폰을 대상으로 쓸 때

1. iPhone 미러링을 실행합니다 (**아이폰은 잠긴 상태**로 근처에 있어야 합니다)
2. 대상 앱을 띄웁니다
3. 미러링 창에 포커스를 줄 때는 **창 제목 표시줄**을 클릭하세요.
   아이폰 화면 영역을 클릭하면 그 클릭도 탭으로 들어갑니다
4. 대상 지점에 커서를 올리고 `⌥⌘C` → `⌥⌘S`

연타 중에는 아이폰을 직접 쓸 수 없습니다. 미러링은 아이폰이 잠겨 있어야
동작하기 때문입니다.

## 속도의 한계

**설정은 5ms까지 내려가지만 그대로 반영되지는 않습니다.** 연타는 네 개의 층을
통과하고, 아래로 갈수록 병목이 심해집니다.

| 층 | 한계 | 측정 |
|---|---|---|
| 타이머 스케줄링 | 2ms (500 tap/s) | 측정 완료 |
| CGEvent 전송 | 미지 | 미측정 |
| iPhone 미러링 전송 | 미지 — 실제 병목으로 추정 | 100ms만 확인 |
| iOS 터치 전달 | 프레임 주기 ~8ms(120Hz) / ~17ms(60Hz) | 측정 불가 |

마지막 층이 실질적인 천장입니다. iOS는 터치를 런루프 주기로 전달하므로 한
프레임 안에 들어온 두 탭은 합쳐지거나 앱의 디바운스에 걸릴 수 있습니다.
**5ms 미만은 설정이 되더라도 의미가 없을 가능성이 큽니다.**

팝오버에 **실측 tap/s**가 표시됩니다. 설정값과 실측이 벌어지면 전송이
병목이라는 뜻이니 간격을 올려 맞추세요.

## 안전장치

연타는 커서를 빼앗으므로 끄는 것 자체가 어려워질 수 있습니다. 그래서:

- **긴급 정지** (`⌥⌘.`) — 키 입력을 소비하는 경로라 클릭이 쏟아지는 중에도 반응
- **하드 캡** — 토글 모드도 10분이면 강제 종료
- **포커스 가드** — 시작 시점의 최전면 앱에 고정하고, 다른 앱으로 바뀌면 즉시
  정지. 대상 창을 떠난 뒤 엉뚱한 창을 난타하는 사고를 막습니다
- **커서 복원** — 연타가 끝나면 커서를 원래 자리로 되돌립니다

## 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 아무 반응이 없다 | 권한 부여 후 재시작을 안 함 | 앱 종료 후 재실행 |
| 설정엔 켜져 있는데 거부된다 | 이전 빌드의 유령 권한 항목 | 아래 "권한이 꼬였을 때" |
| 미러링 화면이 검은색 | 대상 앱이 화면 캡처를 차단 | 이 방식으로는 불가 |
| 핫키가 안 먹는다 | 다른 앱이 선점 | 팝오버 배너에 표시됨 |
| 숫자 입력란에 타이핑이 안 된다 | 팝오버가 포커스를 못 받음 | 아이콘을 다시 클릭 |

### 권한이 꼬였을 때

시스템 설정 → 손쉬운 사용에서 Tapper를 **`−`로 제거**한 뒤 `+`로 다시
추가하세요. 토글만 껐다 켜는 것으로는 정리되지 않습니다.

그래도 안 되면 권한 항목을 초기화합니다:

```bash
tccutil reset Accessibility com.ssu.tapper
```

실행 후 앱을 띄우면 권한 요청이 새로 뜹니다. 승인하고 재시작하세요.

## 개발자용

### 빌드

```bash
./build.sh                 # 테스트 → 벤치 → tapprobe → Tapper.app
./build.sh --skip-tests
```

Xcode.app은 필요 없습니다 (CLT의 `swiftc`만 사용). `.app` 번들을 직접 조립하고
서명합니다.

### 테스트

`build.sh`가 앱 빌드 전에 34개를 먼저 통과시킵니다. 실패하면 빌드하지 않습니다.

- **엔진 18개** (`Tests/enginetest.swift`) — 3개 정지 모드, 시작 지연, 하드 캡,
  타이머 중복 차단, 정지 후 잔여 탭 없음, 누름 시간 클램프
- **설정 16개** (`Tests/settingstest.swift`) — 범위 클램프, 1초 단위 정규화,
  NaN 방어, `didSet` 무한 재귀 없음

엔진 테스트는 탭 발행부를 가짜로 주입하므로 **권한도 실제 클릭도 없이** 돌아갑니다.

### 코드 서명과 권한의 관계

손쉬운 사용 권한은 코드 서명의 designated requirement(DR)에 묶입니다.
서명 방식이 재빌드 후 권한 유지 여부를 결정합니다.

| 서명 | DR | 재빌드 시 |
|---|---|---|
| ad-hoc (`-s -`) | `cdhash H"..."` | **깨진다** — 바이너리 해시가 바뀜 |
| 자체 서명 인증서 | `identifier + certificate leaf H"..."` | 유지된다 |

그래서 `setup-signing.sh`로 자체 서명 인증서를 만들고 `build.sh`가 자동으로
찾아 씁니다. 인증서가 없으면 ad-hoc으로 떨어지면서 경고합니다.

`CSSMERR_TP_NOT_TRUSTED`는 자체 서명이라 정상입니다. 신뢰 여부는 Gatekeeper
검증에만 관여하고 서명 자체에는 영향이 없습니다.

`setup-signing.sh`는 macOS에서 걸리는 함정 두 개를 처리합니다. OpenSSL 3는
비공개 키를 PKCS#8로 쓰지만 `security`는 전통적 RSA 포맷만 읽고, OpenSSL 3의
PKCS#12는 `security`가 아예 못 읽습니다. 그래서 p12를 우회해 키와 인증서를
따로 가져옵니다.

### 왜 맥 앱인가

비탈옥 iOS에는 **다른 앱에 터치를 주입하는 API가 없습니다.** 앱 샌드박스가
금지합니다. 그래서 실행 주체는 맥 앱이고, iPhone 미러링을 경유해 효과가
아이폰에 떨어집니다.

미러링 경로가 막히면(대상 앱의 캡처 차단 등) 대안은 XCUITest/WebDriverAgent이고
Xcode 설치와 기기 개발자 모드가 필요합니다.

### 측정 도구

```bash
./build/ratebench        # 엔진 스케줄링 한계 측정
./tapprobe here 9 100    # 커서 지점을 100ms 간격으로 9회 탭
./tapprobe ax            # 손쉬운 사용 권한 보유 여부
```

반영 횟수를 정확히 세려면 iOS 계산기에서 `1` 버튼을 9회 탭하고 표시창의 `1`
개수를 확인합니다. 유실을 정확히 셀 수 있는 가장 쉬운 방법입니다.

### 구성

```
Sources/
  Clicker.swift        코어 엔진. 탭 발행부를 주입받아 테스트 가능하게 분리
  Settings.swift       UserDefaults 영속 설정, 값 정규화
  HotKeys.swift        Carbon 전역 핫키 (키 입력을 소비해 대상 앱으로 새지 않음)
  AppController.swift  엔진·핫키·안전장치 결합, 포커스 가드
  PopoverView.swift    SwiftUI UI
  main.swift           NSStatusItem 진입점
Tests/
  enginetest.swift     엔진 테스트 (권한·클릭 없이 실행)
  settingstest.swift   설정 정규화 테스트
  ratebench.swift      스케줄링 한계 벤치
install.sh             설치 진입점
setup-signing.sh       코드 서명 인증서 생성 (최초 1회)
build.sh               빌드
tapprobe.swift         좌표 탭 검증 CLI
sweep.sh               유실률 스윕 (미러링 경로 실패 시 예비용)
```
